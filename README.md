# Interactive C++ Student Database CLI

An interactive command-line interface (CLI) tool built in C++ utilizing Object-Oriented Programming (OOP) principles and file input/output (`fstream`) for persistent student record management. Designed to be containerized and easily tested by anyone using Docker.

## 🚀 Features
- **Interactive Menu:** Add new student records, view saved records, and manage data dynamically.
- **File Persistence:** Automatically saves and retrieves student data from `student_database.txt`.
- **Docker Support:** Fully containerized for instant execution without needing a local C++ compiler.
